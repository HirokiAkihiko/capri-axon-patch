# Capri 1.40 — Axon mod

Patched build of **Capri 1.40** (`app.capri`, by Notasakin / @caprimobile) with
one change: an added brain provider **AxonAgent**
(`https://api.axonagent.xyz/v1`), recognised automatically when you paste a
key with the `limo-` prefix. Everything else is byte-identical in behaviour
to the audited 1.40 build; the patch adds a single entry to the provider
list in `BrainKt`.

- Version: `1.40-axon` (versionCode 46)
- Signed with a dedicated mod key (SHA-256
  `74410280e69165e3045cebae6ea18b79af2a21d9561babb66d520954ec550ab4`), not the
  original Capri key — uninstall the existing Capri before installing, and
  channel updates will not install over this build.
- APK SHA-256: `39c115eb478d961546132b65402b77d9647107d5b4bcea8b0f8be06a21b7ad90`

Download the APK from the **Releases** page (tag `capri-1.40-axon`).
